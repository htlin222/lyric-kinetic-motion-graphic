# 11. Hard-won Lessons 清單

開工前先讀一遍。

## 時間對齊
- [ ] **人聲先分離（Demucs）**，所有 onset 和 Whisper 都在人聲軌上做。
- [ ] Whisper 只當錨點。**用歌詞表做 DP 對齊**，不要直接用轉寫結果。
- [ ] **歌詞表 ≠ 實際唱的內容**：拿 Whisper 轉寫逐句比對，找出重複的 hook 和 chant。
- [ ] 中文絕對不要平均分配。**每個字都要有自己的音節 attack**。
- [ ] onset 用 `backtrack=True`、`hop=128`。音節用包絡谷值法。兩者合併後去重（45 ms）。
- [ ] snap 窗口不對稱（−0.16 / +0.12），因為 Whisper 偏晚。
- [ ] 字落在靜音裡，就往後找第一個有聲的 attack。
- [ ] 夾在英文中間的中文，下界用前一個字的**結束**時間。
- [ ] beat grid 只拿來 sanity check，不拿來 snap。
- [ ] **每一段都要看 `plot_align` 圖。** 兩個獨立方法吻合才算數。

## 動態
- [ ] impact（落地、震動、閃光）放在 attack +20 ms，slam 提早 110 ms 開始。
- [ ] 英文提早 50 ms 開始 glide。
- [ ] 震動要有衰減，閃光要節制。
- [ ] 兩種語言兩種重量：輕的 glide 對重的 stamp。

## 轉場
- [ ] 段落邊界對在第一個音節，不是對在拍點。
- [ ] 360° 旋轉的切點在 `inOut⁻¹(0.25)`（側面），不是 0.5（背面）。
- [ ] 不要做「寬度兩次縮到 0」的翻轉，看起來就像掉幀。
- [ ] 鏡頭速度要平滑，不能突然改變。
- [ ] 舊 shot 和新 shot 重疊越短越好。

## 渲染
- [ ] 背景一律先填滿不透明底色（不然會殘影）。
- [ ] 每種字體都要確認有沒有 CJK 字形（Anton 沒有 → 會出現豆腐）。
- [ ] renderer 寫成 deterministic，才能出 still、平行渲染、在 CI 重現。
- [ ] 檢查逐幀 strip 時用 `%{pts}`，不要用 `n`。

## 溝通
- [ ] 先給 720p 預覽讓人看，回饋（「1:45 卡卡的」「字要對齊聲音」）通常比自己檢查更快抓到問題。
- [ ] 使用者說「卡」的時候，先查**內容和聲音有沒有對上**，再查轉場，最後才查效能。
