# 5. 讓拍點「有感覺」：impact 要落在哪一幀

時間對了還不夠。**動畫的哪一個瞬間**對到 attack，決定了觀眾覺不覺得「有對到」。

## 核心規則：impact 對 attack，動畫要提早開始
| 元素 | 動畫 | 時間設定 |
|---|---|---|
| 中文 stamp | 從 2.8× 縮回 1× 砸下（inQuad） | 從 `attack + 20ms − 110ms` 開始，**在 attack + 20 ms 落地** |
| 落地瞬間 | 畫面震動、白閃、色差、金色墨點、紅色印章框 | 全部掛在 `attack + 20 ms` |
| 英文 glide | yaw 70°→0、往上漂、3 幀殘影（outExpo 0.42 s） | `attack − 50 ms` 開始，約 100 ms 內就看得到 80% |
| Hero 大字 | 逐字母翻入（outBack 0.24 s） | 第一個字母在 `attack + 20 ms` 落地 |
| 副歌 REVERSE | 每個 token 內字母由右往左、從鏡像翻正 | 第一個字母在該 token 的 attack 落地 |
| 多字中文 | **每個字在自己的 attack 砸下** | 印章框在最後一個字落地後才合上 |

## 為什麼是 +20 ms、−110 ms
- 用 slam（從大縮小）的話，**最有力的那一幀是縮到 1× 的瞬間**。如果從 attack 才開始縮，視覺落地就晚了 110 ms，觀眾會覺得「慢半拍」。
- 實務經驗：畫面比聲音**早**一點，很容易被察覺；**晚 20 ms 左右**反而最「黏」。所以落地點放在 +20 ms。
- 英文是柔的動作，沒有明確的落地點，提早 50 ms 開始，讓字在聲音出來時已經看得清楚。

## 「有感覺」的加成
- **震動要有衰減**：`amp · e^{-9d} · sin(83d)`，0.6 s 內消失。主字 16、次要字 8、爆點 34。
- **閃光只給重要的點**：副歌第一個字 0.35、爆點 0.55，其他都很小。全部都閃就等於全部都不閃。
- **一個語言一種重量**：英文輕飄飄，中文像蓋章。「切換語言」本身就變成視覺笑點，也讓拍點更明顯。
- **逐字 slam > 整詞 slam**：雙語國際競爭力逐字砸下，配上逐字震動，就是整首歌的爆點。
